Backup — Collections & History

Chrome erases an extension's storage when the extension is removed, so saved requests and history are mirrored to a file you choose. Once linked, every change is written to it automatically, and it is read back automatically each time the panel opens.

Restore an existing backup

Pick a backup file you already have — for example after re-adding the extension. Its contents are merged back into Collections and History, and the file is linked for future auto-saves.

Create a new backup file

Choose where to keep ciphernet-backup.json. Your current Collections and History are written to it right away.

Re-authorise the backup file

Chrome drops file permissions when the browser restarts. Grant access once and auto-save resumes.

The backup file is plain JSON on your disk. Bearer tokens saved with a request are encrypted in it (not plaintext) — but that's obfuscation, not a secrecy boundary, so still keep it somewhere private. AES keys and IVs are never written to it at all.
