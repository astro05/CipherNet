# 2. Network Request Capture

Capture every network request from the inspected page.

Support:

* Fetch API
* XMLHttpRequest
* Document requests
* Script
* CSS
* Images
* Fonts
* WebSocket
* EventSource
* Media
* Other resources

For every request collect:

* Request ID
* URL
* Method
* Scheme
* Domain
* Path
* Query
* Protocol
* Remote Address
* Status Code
* Status Text
* Type
* Initiator
* Priority
* Timing
* Transfer Size
* Encoded Size
* Decoded Size
* Content Length
* Cache Status
* Service Worker Info
* Security Details
* Request Headers
* Response Headers
* Cookies
* Request Body
* Response Body
* Raw Response
* MIME Type
* HTTP Version
